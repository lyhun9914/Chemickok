# 냥신 점괘 운영 가이드

로그인·결제를 실제로 켜는 순서와 오픈 전 점검 목록입니다. 키를 넣는 곳은 모두 **Vercel → 프로젝트(chemickok) → Settings → Environment Variables**이고, 넣은 뒤에는 **Deployments → 맨 위 배포 → ⋯ → Redeploy**를 해야 반영됩니다.

---

## 1. 로그인

코드는 카카오·네이버·구글·이메일 네 가지가 모두 들어가 있습니다. 키가 들어간 것만 로그인 화면에 버튼이 나타납니다.

| 방식 | 지금 상태 | 할 일 |
| --- | --- | --- |
| 카카오 | 켜져 있음 | 없음 |
| 이메일 | 이번 배포로 바로 켜짐 | (선택) 비밀번호 재설정 메일 설정 — 1-4 |
| 네이버 | 키 없음 | 1-2 |
| 구글 | 키 없음 | 1-3 |

### 1-1. 공통으로 쓰는 주소

- 서비스 주소: `https://chemickok.vercel.app`
- 네이버 Callback URL: `https://chemickok.vercel.app/api/auth/naver/callback`
- 구글 리디렉션 URI: `https://chemickok.vercel.app/api/auth/google/callback`

나중에 도메인을 사면 주소를 새 도메인으로 바꿔서 같은 자리에 추가로 등록합니다.

### 1-2. 네이버 로그인

1. https://developers.naver.com 에 로그인 → **Application → 애플리케이션 등록**
2. 애플리케이션 이름: `냥신 점괘` · 사용 API: **네이버 로그인**
3. 제공 정보: **별명**(필수), **이메일**(선택)
4. 로그인 오픈 API 서비스 환경: **PC 웹**, **Mobile 웹** 둘 다 추가하고, 서비스 URL과 Callback URL을 위 1-1 주소로 입력합니다.
5. 등록하면 나오는 **Client ID / Client Secret**을 Vercel에 넣습니다.
   - `NAVER_CLIENT_ID` = Client ID
   - `NAVER_CLIENT_SECRET` = Client Secret
6. 처음에는 "개발 중" 상태라 **멤버 관리에 등록한 네이버 아이디만** 로그인됩니다. 모든 사람이 쓰려면 **검수 요청**을 해야 합니다. 로그인 버튼 화면 캡처와 개인정보처리방침이 필요하며, 처리까지 며칠 걸립니다. 개인정보처리방침은 사이트 맨 아래 링크를 쓰면 됩니다.

### 1-3. 구글 로그인

1. https://console.cloud.google.com → 새 프로젝트 만들기 (이름: `nyangsin`)
2. **API 및 서비스 → OAuth 동의 화면**(또는 "Google 인증 플랫폼")
   - 사용자 유형: **외부**
   - 앱 이름 `냥신 점괘`, 지원 이메일 `chemickok@gmail.com`
   - 범위(scope)는 기본인 `openid`, `email`, `profile`만 씁니다. 민감한 범위가 아니어서 별도 심사 없이 게시할 수 있습니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 리디렉션 URI: 1-1의 구글 주소
4. 나오는 값을 Vercel에 넣습니다.
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
5. 동의 화면을 **"테스트"에서 "프로덕션으로 게시"** 로 바꿔야 누구나 로그인할 수 있습니다. 테스트 상태에서는 등록한 테스트 사용자만 됩니다.
6. 구글은 카카오톡·인스타그램 안의 브라우저에서 로그인을 막습니다. 그래서 그 안에서는 구글 버튼을 숨기고 "다른 브라우저로 열기"를 안내하도록 해 두었습니다.

### 1-4. 이메일 회원가입 (비밀번호 재설정 메일)

- 가입과 로그인은 따로 설정할 것이 없습니다. 비밀번호는 복원할 수 없는 방식(scrypt)으로 저장됩니다.
- **비밀번호 찾기**를 쓰려면 메일 발송 계정이 필요합니다. 설정하지 않으면 "고객문의로 알려 달라"는 안내가 나갑니다. Gmail로 설정하는 방법:
  1. chemickok@gmail.com 구글 계정 → **보안 → 2단계 인증 켜기**
  2. **보안 → 앱 비밀번호** → 이름 `nyangsin` → 16자리 비밀번호 생성
  3. Vercel에 넣기: `SMTP_USER` = `chemickok@gmail.com`, `SMTP_PASS` = 16자리(공백 없이)
  4. Gmail은 하루 약 500통까지 보낼 수 있습니다.
  - `SMTP_USER`와 앱 비밀번호는 **반드시 같은 계정**이어야 합니다. 다르면 "메일 계정 로그인 실패"가 뜹니다.
  - 보내는 계정이 chemickok이 아니어도 됩니다. 손님이 메일에 **답장**하면 고객문의 주소(chemickok@gmail.com)로 갑니다. 다른 주소로 받으려면 `MAIL_REPLY_TO`를 넣습니다.
- 가입 선물 냥은 **카카오·네이버·구글 가입에만** 지급됩니다. 이메일은 무제한으로 만들 수 있어 선물을 받으면 악용될 수 있기 때문입니다.

## 2. 결제 (토스페이 · 카카오페이)

### 2-1. 구조

- 결제창은 **토스페이먼츠** 하나로 연결되어 있습니다. 결제 화면에는 네 버튼이 있습니다.
  - **토스페이** → 토스 앱이 바로 열립니다.
  - **카카오페이** → 카카오페이가 바로 열립니다.
  - **네이버페이** → 네이버페이가 바로 열립니다.
  - **카드·기타** → 토스 통합 결제창이 열리고, 카드사와 다른 간편결제를 고를 수 있습니다.
- 그래서 카카오페이·네이버페이와 따로 계약할 필요 없이, **토스페이먼츠 계약 하나 + 간편결제 추가 신청**으로 끝납니다.

### 2-2. 계약 순서

1. https://www.tosspayments.com → **전자결제 신청**
   - 필요한 것: 사업자등록증(넥스트원), 통신판매업 신고번호(이미 있음), 대표자 정보, 정산 계좌
   - 판매 상품: "디지털 콘텐츠(운세·심리 콘텐츠)"로 설명합니다. 운세·점술 업종은 카드사 심사에서 추가 확인을 요청할 수 있으니, 사이트 주소, 이용약관, 환불 규정을 미리 보여 줄 수 있게 준비해 두세요. 사이트 하단에 이미 있습니다.
2. 심사가 끝나면 **상점관리자 → 결제수단** 에서 **토스페이**, **카카오페이**, **네이버페이** 추가를 신청합니다. 신청이 승인되기 전에는 그 버튼을 눌러도 결제창에서 "사용할 수 없는 결제수단"으로 나옵니다. 간편결제사별로 심사가 따로 있으며 보통 수일에서 2주 걸립니다.
3. **개발자센터 → API 키** 에서 **"API 개별 연동 키"**를 확인합니다. "결제위젯 연동 키"가 아닙니다. 이 서비스는 결제창 방식(SDK v2 `payment()`)이라 개별 연동 키를 써야 합니다.

### 2-3. 키 넣기 — 먼저 테스트 키로

| 변수 | 테스트 단계 | 오픈 |
| --- | --- | --- |
| `NEXT_PUBLIC_TOSS_CLIENT_KEY` | `test_ck_…` | `live_ck_…` |
| `TOSS_SECRET_KEY` | `test_sk_…` | `live_sk_…` |
| `NEXT_PUBLIC_PAYMENT_TEST_MODE` | `false` | `false` |
| `PAYMENT_TEST_MODE` | `false` | `false` |

- 두 TEST_MODE 값을 `false`로 바꾸는 순간부터 진짜 토스 결제창이 열립니다. 테스트 키를 쓰는 동안은 실제로 돈이 나가지 않습니다.
- 테스트 키로 다음을 직접 해 봅니다.
  - 비회원 바로 결제(토스페이 / 카카오페이 / 카드)
  - 냥 충전
  - 결제 완료 화면 새로고침 — 다시 눌러도 "실패"가 뜨지 않게 고쳐 두었습니다.
- 모두 확인되면 라이브 키로 바꾸고 Redeploy합니다.

### 2-4. 오픈 전에 꼭

1. **테스트 모드로 쌓인 냥 정리**
   - 지금은 테스트 모드라 누구나 공짜로 냥을 충전할 수 있습니다.
   - 오픈 직전에 Supabase → SQL Editor에서 아래를 실행하세요. 테스트 충전 기록을 지우고 잔액을 다시 계산합니다.

   ```sql
   delete from coin_ledger where reason = 'charge' and ref like 'test-%';
   update wallets w
     set balance = greatest(0, coalesce((select sum(delta) from coin_ledger l where l.user_id = w.user_id), 0)),
         updated_at = now();
   delete from payments where order_id like 'test-%';
   delete from users where provider = 'dev';  -- 개발용 테스트 계정
   ```

2. **카카오 개발자 콘솔 → 앱 → 플랫폼 → Web** 에 `https://chemickok.vercel.app`이 등록돼 있는지 확인합니다. 등록이 안 돼 있으면 카톡 공유 창이 안 뜨고 링크 복사로 바뀝니다.

## 3. 냥 운영

- **관리자 화면 (/admin)**
  - Vercel → Settings → Environment Variables에 `ADMIN_KEY`(16자 이상, 남이 못 맞힐 문자열)를 넣고 다시 배포합니다.
  - `https://사이트주소/admin`에서 그 키로 들어갑니다. 로그인은 12시간 유지되고, 검색엔진에는 노출되지 않습니다.
  - 위쪽 메뉴: 🏠 홈 · 💳 결제·환불 · 👥 회원 · 🪙 가격·세일 · 📢 공지·쿠폰 · 📈 이용 흐름 · 🚨 오류 · 🗂️ 기록 · 🎬 쇼츠. 고른 메뉴는 주소 끝(#pay 등)에 남아서 새로고침해도 그대로입니다.
  - 돈·냥·가격이 바뀌는 버튼은 모두 **"다음: 확인하기" → 내용 확인 → 한 번 더 누르기** 순서입니다. 확인 창에서 "돌아가기"를 누르면 아무것도 바뀌지 않습니다.
- **🏠 홈**: 오늘과 어제(방문, 면담, 결제, 매출, 새 회원, 환불), 알림(테스트 결제, 오류, 켜진 세일·공지), 자주 쓰는 메뉴 바로가기, 전체 숫자.
- **💳 결제·환불**
  - 닉네임·이메일·주문번호로 찾고, 기간(오늘·7일·30일·90일)과 "환불만"으로 거릅니다. 위에 그 기간의 매출·환불·순매출 합계가 나옵니다.
  - 결제마다 **누가 결제했는지**(닉네임·이메일 또는 가입 방법)가 보이고, 이름을 누르면 그 회원 화면으로 갑니다.
  - **📥 엑셀로 내려받기**: 이번 달 · 지난달 · 고른 기간의 결제·환불 내역(CSV)을 받습니다. 엑셀에서 한글이 깨지지 않게 열립니다.
- **👥 회원**: 닉네임·이메일·초대 코드·회원 ID로 찾습니다. 회원을 열면 남은 냥, 결제(여기서도 환불 가능), 냥 기록(충전·점괘·쿠폰·출석 등 알아보기 쉽게)이 보입니다. **냥 넣기·빼기**는 사유를 꼭 적어야 하고, 작업 기록에 남습니다.
- **🪙 가격·세일 (다시 배포 없이 바로 반영)**
  - **충전 묶음**: 냥 수, 가격(10원 단위), 딱지(예: 인기)를 바꾸고 묶음을 더하거나 뺍니다. 냥당 가격과 할인율이 바로 계산됩니다.
  - **점괘마다 드는 냥**: 상품별로 1~20냥. 비회원이 바로 결제하는 가격은 같은 냥 수의 묶음 가격을 따라갑니다 (예: 궁합 2냥 → 2냥 묶음 가격).
  - 저장하면 바뀌는 항목이 "전 → 후"로 나오고, 한 번 더 눌러야 적용됩니다. 손님 화면(홈의 복채 안내, 상품 카드, 결제창, 복주머니)에 바로 반영됩니다. 이미 충전한 냥과 열어 둔 점괘는 그대로입니다.
  - 손님이 바뀌기 전 가격으로 결제창을 열었다면 결제 승인 전에 막히고 "가격이 방금 바뀌었어요"가 안내됩니다 (돈은 나가지 않음).
  - **충전 세일**: 이름, 할인 %(가격), 냥 더 주기 %(보너스 냥, 묶음별 내림), 시작·끝 시간. 끝나는 시간이 지나면 저절로 꺼집니다. 켜져 있는 동안 복주머니에 세일 안내와 원래 가격(취소선)이 보이고, 홈 복채 안내에 "충전 세일 중"이 붙습니다. 환불할 때 회수할 냥은 보너스까지 포함한 실제로 들어간 냥입니다.
  - "처음 가격으로 채우기"는 코드에 있는 원래 가격(`src/lib/config.ts`)을 채워 넣기만 합니다. 저장해야 적용됩니다.
  - ⚠️ 토스 심사 중에는 심사 때 보여 준 가격을 되도록 유지하세요.
- **📢 공지·쿠폰**
  - **홈 공지 배너**: 공지 · 이벤트 · 점검 중 하나를 고르고 문구(120자)와 링크(선택, 예: `/?game=exam` 또는 `https://…`)를 넣어 띄웁니다. 홈 맨 위에 보이고, 손님이 ✕로 닫으면 그 방문 동안은 안 보입니다.
  - **쿠폰**: 코드(비우면 8자리 자동), 주는 냥, 선착순 인원, 마감일, "카카오·네이버·구글 가입 회원만"(기본 켬, 이메일 계정을 여러 개 만들어 받는 걸 막음)을 정해 만듭니다. 회원 한 명당 한 번만 받습니다. 목록에서 받은 인원을 보고, 코드를 눌러 복사하고, 끄고 켤 수 있습니다.
  - 손님은 **복주머니 → "🎟️ 쿠폰 코드가 있나요?"**에 코드를 넣습니다. 틀린 코드를 연달아 넣으면 잠시 막힙니다.
- **🗂️ 작업 기록**: 환불, 냥 넣기·빼기, 가격·세일·공지 변경(전·후 내용), 쿠폰 만들기·끄기, 엑셀 내려받기, 관리자 로그인(성공·실패, IP)이 남습니다. **모르는 로그인이나 로그인 실패가 많이 보이면 `ADMIN_KEY`를 바꾸세요.**
- **📧 매일 아침 요약 메일**: 매일 오전 9시쯤(Vercel Cron) 어제의 매출·결제·환불·방문·면담·새 회원·쿠폰·오류를 그 전날과 비교해 `ADMIN_EMAIL`로 보냅니다. Vercel 환경 변수 `CRON_SECRET`이 있어야 합니다 (넣어 두었음). Vercel Hobby 요금제는 정각에서 최대 1시간 늦게 올 수 있습니다.
- **코드로 바꾸는 값** (`src/lib/config.ts`, 다시 배포 필요): `WELCOME_COINS` 가입 선물, `INVITE_COINS` / `INVITE_LIMIT` 친구 초대 선물과 1인당 최대 인원, 출석 보상.
- **📈 이용 흐름 (관리자 화면)**

- **환불 요청이 오면**
  - 관리자 화면 💳 결제·환불(또는 👥 회원)에서 그 결제의 **↩ 환불**을 누릅니다. 환불 금액(기본: 전액)과 회수할 냥(기본: 그 충전으로 들어간 냥), 사유를 넣고 **"다음: 확인하기"** → 확인 창에서 회원·결제·환불 금액·회수할 냥·처리 방법을 보고 **"○○원 환불하기"**.
  - 순서: 냥을 먼저 회수 → 토스 결제 취소(사유가 토스에도 전달) → 환불 기록. 토스 취소가 실패하면 회수한 냥은 자동으로 되돌아갑니다.
  - 회원이 이미 냥을 썼으면 전액 환불이 막히고 남은 냥이 안내됩니다. 회수할 냥과 금액을 줄여 부분 환불하세요 (예: 1,490원·2냥 충전 중 1냥만 남았으면 745원·1냥).
  - 이 기능이 생기기 전에 결제된 건은 토스 결제 키가 없어서 버튼으로 취소가 안 됩니다. 토스페이먼츠 상점관리자에서 직접 취소한 뒤, "토스에서 이미 취소함"을 체크하고 누르면 냥 회수와 기록만 합니다.
  - 매출 숫자는 환불을 뺀 금액이고, "30일 환불"에 따로 보입니다.
  - 관리자 화면을 못 쓸 때는 토스 상점관리자에서 취소한 뒤 아래처럼 Supabase SQL Editor에서 냥을 직접 빼도 됩니다.

  ```sql
  -- 고객 찾기 (이메일 또는 닉네임)
  select id, provider, nickname, email from users where email = '고객@이메일' or nickname = '닉네임';
  -- 남은 냥 확인
  select * from coin_ledger where user_id = '고객 id' order by id desc;
  -- 냥 빼기 (예: 5냥 환불) — 직접 기록을 남기고 잔액을 줄입니다
  insert into coin_ledger (user_id, delta, reason, ref, balance_after)
    select '고객 id', -5, 'refund', '환불 주문번호', balance - 5 from wallets where user_id = '고객 id';
  update wallets set balance = balance - 5, updated_at = now() where user_id = '고객 id';
  ```

- **보상으로 냥 넣어 주기**: `select coin_add('고객 id', 1, 'admin', '보상-날짜-사유');` — 같은 사유 문자열은 한 번만 들어갑니다.
- **환불 규정**: 이용약관 제4·5조에 넣어 두었습니다. 기본은 "환불 불가"이고, 법으로 막을 수 없는 경우만 남겼습니다.
  - 냥으로 연 점괘(감정서)는 여는 즉시 제공되는 디지털 콘텐츠라 환불되지 않습니다. 무료 맛보기를 먼저 보여 주고, 결제 전에 동의 체크를 받으므로 전자상거래법 제17조 제2항 제5호에 따라 청약철회가 제한됩니다.
  - 충전한 냥은 7일 안에 하나도 쓰지 않은 경우에만 환불합니다. 이 7일은 법(전자상거래법 제17조)이 정한 최소 기간이라 약관으로 없앨 수 없습니다(없애는 조항은 무효).
  - 7일이 지났거나 일부라도 쓴 충전분, 가입·출석·초대 선물로 받은 무료 냥, 다른 사람에게 선물받은 냥은 환불하지 않습니다. 무료·선물 냥이 먼저 쓰입니다.
  - 회사 잘못(점괘가 안 열림, 중복 결제 등)은 전액 돌려줍니다.
  - 미성년자가 법정대리인 동의 없이 결제한 경우는 법에 따라 취소될 수 있습니다(제6조).
