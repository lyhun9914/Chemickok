# 결제 오픈 뒤 공격적 성장 계획 (초안 · 승인 전)

작성 2026-11-14 · 홍보 담당(`nyang-marketing`). 이 문서는 **계획**이다. 게시·계정 만들기·돈·키 변경은 하나도 하지 않았다(Windsor `list_actions` 읽기만 함).
기준: 결제 오픈일을 D+0 으로 둔다. 11/13 운영자 결정("결제가 열린 뒤부터 공격적으로")은 그대로 지킨다. 아래 D-7 티저는 **운영자 예외 승인이 있어야** 한다(결정 1번).

표시: **확인** = 이번 조사에서 근거를 찾음(출처 6번) · **추측** = 근거 못 찾음, 내 판단 · **직접확인** = 이 세션 도구로 읽어서 확인.
주의: Meta·TikTok·Google 공식 문서 주소는 이 세션 네트워크에서 열리지 않았다. 공식 문구를 인용한 검색 결과로만 확인했고, 수치가 걸린 곳은 오픈 전에 공식 화면에서 한 번 더 본다.

## 1. 사이트 안 바이럴 고리

### 이미 있는 것 (코드 직접확인)

| 기능 | 위치 | 지금 하는 일 |

### 빈 곳 (직접확인)

1. **공유 단추를 눌렀다는 기록이 없다.** `track` 단계는 start·q·result·paysheet·paid·game 뿐이다. 몇 명이 어디로 공유했는지 모른다.
2. **`utm_source` 하나만 저장**(40자). `utm_medium`·`utm_campaign` 은 저장 안 한다.
3. 공유 경로가 **카톡·인스타 스토리 두 갈래뿐**. Threads·X·링크 복사 단추가 따로 없다.
4. 스토리 이미지에 "친구 태그하고 같이 보기" 같은 **다음 행동 문구가 없는지는 확인 못 함**(이미지 모양은 화면으로 보지 않음, 추측).
5. 인스타 스토리의 **링크 스티커·"Add Yours"·투표 스티커는 API 로 못 붙인다**(Windsor `create_story` 는 `image_url`·`video_url` 둘뿐, 직접확인). 사람이 올릴 때 붙여야 하므로 카드 안에 짧은 주소와 안내가 있어야 한다.
6. 2027 신년운세 **밈처럼 퍼질 한 줄 카드**가 없다(12/1 시즌이 가장 큰 기회).

### 제안 5가지 (효과 ÷ 노력 순)

| 순위 | 기능 | 어떻게 | 노력 |
| --- | --- | --- | --- |
| 1 | **스토리 카드 개편 + 공유 후 넛지** | 9:16 카드에 큰 한 줄("나는 ○○ 고양이"), 스티커를 붙일 빈 영역, 아래 짧은 주소. 공유 직후 "링크 스티커 붙이고 친구 한 명 태그해라냥" 안내. 공유 단추에 Threads·링크 복사 추가 | S~M |
| 2 | **초대 보상 단계 올리기** | 지금 1냥×20명은 유지. 3명·10명에 부적 스킨·배지 같은 비용 없는 보상 추가. 초대 현황("친구 2명 왔다냥") 표시 | S |
| 3 | **2027 신년 밈 카드** | 총운 한 줄 + "올해의 고양이" + 일반·레어·전설 등급(수집·자랑 욕구). 같은 사람도 다른 등급을 보고 싶어 다시 해 봄(오늘 결과는 고정, 등급은 입력 기준) | M |

**먼저 할 전제(S):** 공유 단추 누름을 `track` 에 `share` 단계로 추가(채널: 카톡·스토리·복사·Threads), `utm_medium`·`utm_campaign` 저장. 이게 없으면 위 5개의 효과를 못 잰다. 개발 담당에게 넘길 일이다(홍보 담당은 코드를 고치지 않음).
내 권고: 오픈 전에 **전제 + 1번 + 2번**, 오픈 뒤 D+7 쯤 3번·4번.

보상 비용 주의(추측): 냥은 디지털이라 한계비용은 낮지만, 감정서 풀이 원가·결제 수수료 구조는 내가 모른다. 보상 상한은 운영자가 정한다.

### 2-3. 확인한 것 vs 추측한 것

확인(근거 있음)
- TikTok 심사 안 받은 클라이언트는 비공개 보기만 가능, 풀려면 감사 필요(TikTok 문서 문구를 인용한 검색 결과). 심사 기간·기준은 공개돼 있지 않음.
- Threads 공식 API: 하루 250건(움직이는 24시간), 글 500자, 답글 별도 1,000건. 2단계(만들기 → 올리기).
- YouTube `videos.insert`: 2020-07-28 이후 만든 미확인 API 프로젝트의 업로드는 비공개로 제한.
- 네이버 블로그 글쓰기 API 종료(뉴스핌 2020-04-13 보도, 5월 6일부터).
- 카카오 친구톡 종료·브랜드 메시지 대체(솔라피 안내).
- X 요금제 변경(제3자 여러 곳이 같은 수치, 공식 요금표는 못 열어봄).

추측(근거 못 찾음, 오픈 전 확인)
- Threads 계정이 인스타 계정과 이어져 있어야 하는지(자료가 서로 다름). Windsor 연결 때 화면에서 확인.
- TikTok 심사에 걸리는 기간. 당근 비즈프로필에 공개 글쓰기 API 가 없다는 것(못 찾았을 뿐, 없다고 확정 아님).
- 네이버 카페 글쓰기 API 가 없다는 것(검색 API 만 나옴).
- 커뮤니티별 홍보 규정, 한국 10~30대의 채널별 비중.

### 2-4. 자동화 현실 요약

Claude 가 **직접 올릴 수 있는 곳은 인스타 + (연결하면) Threads** 둘뿐이다. TikTok·Shorts·네이버·당근은 소재와 캡션을 한 번에 묶어 주고 운영자가 올린다. 운영자 손이 드는 시간은 하루 약 15~20분(TikTok·Shorts 업로드 + 네이버·당근 주 2~3회)으로 잡는다(추측).
수동 업로드를 줄이는 길은 두 가지다: ① TikTok·YouTube 감사 신청(수 주, 기간 비공개), ② 제3자 예약 도구(대행 도구가 감사 받은 앱을 쓰는지는 확인 못 함, 개인정보·비용 검토 필요). 둘 다 첫 4주에는 하지 않고, 반응이 오면 결정한다.

## 3. 콘텐츠 엔진 (한 번 만들어 여러 곳에)

원칙: Remotion 으로 만든 마스터 영상 1개 + 1080x1920 정지 이미지 1장 + 4:5 카드뉴스 → 채널별로 자르기만 한다. 캐릭터는 원본 SVG, 안전영역(위아래 250px) 지킨다. 외부 생성 도구(Artlist)는 쓰지 않는다(무료 우선).

| --- | --- |
| Remotion 9:16 영상 15~20초 | 인스타 릴스 · 인스타 스토리(60초 이하) · TikTok · Shorts · Threads 영상 링크 글 요약 |

**같은 세로 영상 돌려쓰기**
- 인스타 릴스 → Claude 가 올림(Windsor).
- TikTok·Shorts → 같은 mp4, 캡션·해시태그만 채널별로 다시 씀. 운영자가 앱에서 올림(첫 1초 문구를 바꾼 판이면 더 좋음).

- X → 영상 올리기는 수동, 낮은 우선.
